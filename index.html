📖 Algorithmic Complexity Guide (Big-O Cheat Sheet)

Big-O notation describes the limiting behavior of an algorithm when input size $n$ approaches infinity:

Notation Name Description & Example
O(1) Constant Direct array index lookup, hash map retrieval.
O(log n) Logarithmic Binary search on sorted arrays, balanced search trees.
O(n) Linear Single-pass traversal over an array or linked list.
O(n log n) Linearithmic Comparison sorting algorithms (Merge Sort, HeapSort, QuickSort avg).
O(n²) Quadratic Two-level nested loops, bubble sort, pairwise comparisons.
O(n³) Cubic Three-level nested loops, naive matrix multiplication.
O(2ⁿ) Exponential Naive recursive Fibonacci, finding all subsets of a set.
O(n!) Factorial Traveling salesperson brute force, generating all permutations.

ℹ️ About Code Complexity Analyzer

Code Complexity Analyzer is a developer workbench designed to demystify algorithmic computational complexity.

It relies on formal Abstract Syntax Tree (AST) structure inspection, recursive call-graph tracing, loop nesting depth calculation, and the Master Theorem for recurrences.

It provides clear, human-readable explanations of worst-case, average-case, and best-case asymptotic bounds, alongside line-by-line cost heatmaps and actionable optimization suggestions.
